# Rehla Agent Skills

هذه المهارات هي بوابة تنفيذ مشروع رحلة. عند تعديل كود أوخطة تنفيذ قابلة للتنفيذ، ابدأ دائمًا بـ[Rehla Implementation Gate](skills/rehla-implementation-gate/SKILL.md)، ثم افتح المهارات المتخصصة التي يحددها سطح المهمة فقط.

| Skill | Use it for |
|---|---|
| [rehla-implementation-gate](skills/rehla-implementation-gate/SKILL.md) | اختيار الخطة والمهمة والتحقق من السلطة والمتطلبات والأدلة |
| [rehla-laravel-package-development](skills/rehla-laravel-package-development/SKILL.md) | إنشاء أوتعديل حزمة Composer محلية وحدودها |
| [rehla-localization](skills/rehla-localization/SKILL.md) | أي package task أوتغيير نص عام أوEN/AR/RTL |
| [rehla-api-contracts](skills/rehla-api-contracts/SKILL.md) | routes وOpenAPI وRequests/Resources وProblem Details |
| [rehla-filament-admin](skills/rehla-filament-admin/SKILL.md) | لوحة Filament والموارد والصلاحيات والأوامر الإدارية |
| [rehla-postgres-integrity](skills/rehla-postgres-integrity/SKILL.md) | migrations والمعاملات والأقفال والتزامن والسجلات الثابتة |
| [rehla-security-and-privacy](skills/rehla-security-and-privacy/SKILL.md) | المصادقة والتفويض والملفات والحقول الحساسة والرفع |
| [rehla-testing-and-verification](skills/rehla-testing-and-verification/SKILL.md) | أي تغيير كود أوخطة تنفيذ واختبارات RED/GREEN والأدلة |
| [rehla-release-operations](skills/rehla-release-operations/SKILL.md) | health/workers/observability/artifact/backup/restore/release |

أمثلة التفعيل: إنشاء package يستعمل البوابة ثم package وlocalization وtesting؛ تغيير checkout يضيف PostgreSQL وsecurity؛ إضافة REST endpoint تضيف API؛ بناء Admin resource يضيف Filament؛ تنفيذ بوابة الإصدار يضيف release operations. لا تعد المهارات إذنًا للنشر أوpush أوتغيير خدمة خارجية.
